# Magicien
## Régle du jeu
Le but est de tuer le dark magician, chaque élément donne des dégats.
Pour Tuer le Dark Magician il y a trois possibiltés:
- L'écraser.
- Le tuer à l'aide des sort.
Si le Dark magician lance une action complémentaire à notre attaque,
un seul prend les dégats de pv : la difference des dégats des 2attaques.
    
Si pendant deux attaques de suite l'utilisateur ne recoit pas de degats,
c'est a dire qu'il a pu obtenir deux attaques complémentaire d'affilé et que ses deux attaques complémentaires étaient de points de dégats plus élevés que le Dark magician, alors on gagne 6 points de vie en plus.

On peut sélectionner à chaque tour une carte parmis quatre cartes parmis les 8 du jeux.
Il est donc impossible de réutiliser deux fois d'affilé la même carte.
Quand le joueur aura 20 lulu, le joueur pourra se deplacer.
Le joueur d'après lancera une attaque sans toucher l'adversaire, sauf si il se déplace.
Toute attaque est comptabilisé si et seulement si le joueur précedent n'a pas bougé.
